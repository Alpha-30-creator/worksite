## p8.25 — Shipping a task does not refresh the cartridge rows it invalidates · 2026-11-03 · @Alpha-30-creator

**What changed:** `ws-ship` §4 gained a cartridge step — four row classes to re-read (anything
naming a **task id**, a **phase**, a **path that does not exist yet**, or a **count**), each with a
grep handle where one exists, and the question *"does this row still read correctly"* rather than
*"is it still true"*, with tense and completeness named as the two shapes a truth check passes
over. Three things make it executable rather than a reminder: it runs **before §3 merges** (§3 now
opens with "§4 first" and says the numbering is the mistake); §7's closing line carries a sixth
fact, `cartridge re-read`, with spellings for rows fixed, for a late run after the merge, and for
`cartridge NOT re-read`; and the commit mechanics are §1's, including the wait for a yes.
`cartridge-schema.md` and `ws-setup`'s template state two writing rules — prefer a decision-record
link to a task id, and write what is true now. `ws-shared/reference.md`'s folder-kind
classification was corrected at the definition, and four restatements brought into line.

**Seven defects in this repo's own cartridge, six of them not false statements.** The headline
finding, measured rather than argued: a row for a top-level `examples/` directory that **no commit
in the repo's history ever contained**, with the word "Exists" added to it later; an enumeration
reading as exhaustive over a directory that had grown to four pages; an `## Open questions` section
holding three settled statements; no row at all for `decisions/`, with six ADRs; "All Markdown
except `audit.sh` — the one executable" against three non-Markdown files and a mode-644 script;
and a security rule — *"`LICENSE` and the npm scope … **Nothing else is**"* — with **three**
exemption mechanisms, not one. Only the first was a false statement.

**Decisions:**
- **The step lives in §4 Docs, not the harvest.** The task's `Why` says "`ws-ship`'s harvest …
  never looks at the cartridge", but the harvest writes the worklog; updating docs is §4.
  *Rejected:* §5, which would have put a repo edit inside the step that writes a record.
- **The question is "reads correctly", not "is true".** *Rejected:* a truth check, measurably —
  six of seven defects were made of accurate clauses, and four of those survived a deliberate
  re-read looking for false ones.
- **Scope is named classes with handles, not the file.** *Rejected:* "re-read the cartridge", which
  is the instruction that gets skipped. The id handle is per-tracker, since a card-titled tracker
  has no grepable id and there the whole file is the scope.
- **The closing line reports it.** *Rejected:* leaving §4 ungated, which is what the task's own
  Notes rejected about a "last reviewed" date — the objection applies to a prompt too.
- **Corrected the folder-kind classification at the pack's definition**, not only where this repo
  restates it: `decisions/` is immutable **in substance** (an item may be amended in place, dated
  and attributed — ADR 0003's header records exactly that), and `records/` holds one standing file
  that is **living**. *Rejected:* reverting this repo's restatement to match the pack, because the
  pack's "never edited" was the false half. This is a pack-wide property change that is **not** in
  p8.25's criteria; it is recorded here because every project keys off it.
- **p8.41 filed** for the executing path check. *Rejected:* building it inline (new scope with its
  own verification burden) and *rejected:* recording it as a limitation only, which review
  correctly called the claim-nobody-enforces objection reproduced.

**Evidence:** `.worksite/tracks/p8.25/verify/cartridge-defects.md` — each defect with the command
that established it, the three rounds' findings, and the claims re-run. Plus, at ship: the step run
on its own cartridge, which produced the measurement now in p8.41's body — resolving backticked
paths from the repo root gives **18 false positives out of 29**, and a short base list resolves 28,
leaving only `docs/agent/journal/`, which the cartridge says is deliberately absent.

**Risks learned:**
- **Three review rounds, twelve must-fixes, and every round found the previous round's fix wrong in
  a new way.** Round one: three documents said the step runs "at harvest" (it is §4), "fix it in
  this PR" sat after the merge step, nothing gated on §4. Round two: I had corrected `layout.md`,
  which **restates** a property the pack **defines** — one of seven sites fixed, the definition
  left asserting the opposite, on a page that says in so many words that the property is the
  pack's. Round three: both counts in the preamble round two rewrote were wrong, there was a third
  exemption mechanism, and §7 had no spelling for the recovery path it had just been given.
- **One exhaustive clause replaced by another, three times, in one security bullet.** "Nothing else
  is" → "four paths" → "two mechanisms" → three. Each correction was narrower, better evidenced,
  and still one mechanism short. The third was `files()` using
  `git ls-files --cached --others --exclude-standard`, so every gitignored path is unscanned —
  verified by scanning two private names under `.worksite/` and watching section 1 report `ok`.
- **I adopted a reviewer's number without re-measuring it.** Round two said the limitations file
  had 49 entries; it has 48, because 49 counts the preamble's own bold lead-in. In the same
  sentence I replaced a stale "seventeen" with a provenance that was also wrong — the file's first
  commit is titled "record **eleven** known limitations". A measurement handed to you is still
  someone else's measurement.
- **"Blanked" was wrong in three places, including the script's own comment.**
  `strip_allowlisted` substitutes the literal token `ALLOWLISTED`, which keeps the halves apart, so
  a private name spliced *around* the allowlisted spelling is missed — where blanking would have
  caught it. The error sat in a file the scan does not read, in a comment describing the function
  below it.
- **The cheapest defect of the day was the one a check found.** The sentence explaining that
  mechanism used a **real private pattern** as its worked example, and `check.sh` section 1 refused
  the commit by name and line. Everything else cost a careful re-read or a reviewer.
