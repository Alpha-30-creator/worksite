## p1.1 — Create the public repo and push the scaffold · 2026-11-01 · @Alpha-30-creator

**What changed:** worksite exists at `Alpha-30-creator/worksite`, public, 22 files. The docs
tree, the cartridge, the roadmap that serves as the tracker, and a leak guard that refuses any
commit carrying a private project name. No skills yet — that is P2.

**Decisions:** the repo is public from the first commit rather than private-then-flipped, because
flipping exposes the whole history anyway; the guard plus stripping before the first commit means
nothing private ever enters it. Named *worksite* over *workshop* (371k repos share that name),
*work-sync* (too easily confused with agent-sync) and *cartridge* (would have cost renaming 14
skill directories). Rejected the full `ws-setup` docs tree after generating it: 15 of 37 files
were folders describing themselves, which is ceremony for content that does not exist.

**Evidence:** `scripts/check.sh` green on the pushed tree — leak scan, skill frontmatter, and
relative links. `.worksite/` confirmed absent from `origin/main` rather than from the working
tree. The pre-commit hook ran on the real commit and passed. The guard was also proven to *fail*
correctly during setup: it refused a draft that used the author's own name inside an example.

**Risks learned:** six entries seeded in `docs/agent/risks/common.md`, the sharpest being that
the leak scan catches names but not voice — a first-person possessive survives it and needs a
human read.

**Docs touched:** the whole initial tree; `docs/decisions/0001` records the source-of-truth
decision.

**PRs:** none. Genesis commit `2052ccd` directly on `main`; the branch-and-PR flow in the
cartridge applies from p1.2 onward.
