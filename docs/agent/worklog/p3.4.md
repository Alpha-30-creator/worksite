## p3.4 — The docs tree has no index · 2026-11-02 · @Alpha-30-creator

**What changed:** `docs/README.md` (new, 124 lines) — a page table of 20 targets grouped by folder,
where each group heading carries the folder's living/immutable kind and what stale means for it, so
criteria 1 and 3 are answered by the same structure. Plus exactly one bullet in the root `README.md`.

**Decisions:**
- **`README.md`, not `00-START-HERE.md`.** The pack's only two mentions of the docs-root entry files
  (`ws-shared/reference.md`:37, `ws-setup`:88) are bare filename lists assigning neither a job;
  GitHub renders `README.md` for a folder; `docs/STATUS.md` already holds the "where is this now"
  role. **Rejected creating both**, which would leave one a callerless stub.
- **Rejected a pure-pointer index.** Criterion 3 requires this page to carry the living/immutable
  classification, so pointing at `engineering/layout.md` cannot satisfy the task. The overlap with
  that page's docs-tree table is therefore **declared rather than removed**, with an explicit
  tie-break: where the two disagree about a folder's contents or provenance, `layout.md` is right
  and this page is stale. Deleting the prose would have traded a declared overlap for a failed
  criterion.
- **`docs/records/` is a folder link plus one named standing page, with no count and no file list.**
  Deliberate: p1.2 was running concurrently and added a dated record there. Verified after both
  merged — the index needed no edit, which is the design working rather than luck.
- **Rejected a single-direction proof.** §3 green only shows no link is broken; an index linking one
  page passes §3. Coverage is proved forward too — every `.md` under `docs/` reachable in at most two
  hops — scripted with §3's own extraction regex so the evidence cannot disagree with the check for
  extraction reasons.
- **Two review findings overturned**, recorded here so no later reviewer re-raises them:
  `engineering/`'s "the same PR as **the thing it describes**" versus the spec's "the code" asserts
  an identical property, and `layout.md` already makes that substitution because a repo of Markdown
  has no application code; and `agent/worklog/`'s `living, append-mostly` adds a true sub-property
  to the spec's flat `living`, which is an addition rather than a mismatch.

**Evidence:** PR #14, CI green in 4s, `check.sh` exit 0 with §1 and §3 `ok`. 20 targets / 0 missing
reverse; 41 docs `.md` / 0 unreachable forward. Independent review answered all eight brief
questions: no Must fix, two Should fixes applied in `5ab84a9`.

**Risks learned:** none new for `risks/`. One worth keeping in view: the review found
`docs/roadmap/README.md` — a *fixed* 20-line page carrying the marker vocabulary and "a pushed commit
is the lock" — reachable only through its folder link, while the index **paraphrased its content**
instead of linking it. The folder-link rationale applies to collections that grow by file and not to
a fixed page inside one, and the index now states that test rather than implying it. The lesson is
that a map which restates a page is worse than one that omits it: it tells the reader the page need
not exist.
